n8n автоматизация для фриланс-бирж

Цель: автоматический анализ заданий, генерация откликов и выполнение IT-задач с использованием бесплатных AI-моделей. Если задача недоступна для бесплатных API — отправляется инструкция для самостоятельной работы с нужным сервисом.

Блок 1: Входные данные (Telegram Bot)

Формат сообщения боту:

Новый заказ
Биржа: Kwork
Ссылка: https://kwork.ru/...
Заголовок: Нужен парсер Wildberries
Описание: [полный текст]
Бюджет: 5000₽
Дедлайн: 3 дня

Цепочка: Telegram Trigger → Function Node (парсинг текста) → сохранение в переменные.

Блок 2: Анализ задания (AI Agent)

  • Google Gemini (free tier)
  • Mistral AI (free tier)
  • Llama через Groq (free tier)

Промпт для анализа:

Проанализируй фриланс-задание. Определи:
1. Тип задачи (разработка, дизайн, текст, другое)
2. Сложность (1-10)
3. Требуемые навыки
4. Реалистичность бюджета
5. Красные флаги (нечёткое ТЗ, слишком дешево, срочно без причины)
6. Рекомендация: брать/не брать + причина

Блок 3: Генерация отклика (Self-Correction Loop)

Шаг 1 (Draft):

Напиши отклик на фриланс-задание. Задание: {{$json.description}}.
Мой опыт: Python 3 года, n8n, автоматизация, парсинг, боты Telegram.
Тон: профессиональный, уверенный, но не высокомерный.
Длина: 100-150 слов.
Структура: приветствие → релевантный кейс → сроки → вопрос по уточнению.

Шаг 2 (Review):

Оцени этот отклик на фриланс-задание по критериям:
- Соответствует ли ТЗ заказчика? (да/нет)
- Есть ли конкретика (цифры, сроки, технологии)? (оценка 1-10)
- Звучит ли как шаблон? (да/нет)
- Есть ли явная польза для заказчика? (да/нет)
- Что улучшить? (конкретные правки)
Если оценка < 8/10 или есть критические замечания → верни JSON:
{improve: true, suggestions: '...'}

Шаг 3 (Refine):

Если improve=true → отправить обратно в Draft с инструкцией:
"Улучши отклик с учётом замечаний: {{$json.suggestions}}"

Условие выхода: 3 итерации ИЛИ оценка ≥ 8/10.

Блок 4: Выполнение IT-задач (Code Node)

Подходит для задач: написать скрипт, спарсить данные, сделать бота.

Промпт:

Ты Python-разработчик. Задача: {{$json.task_description}}.
Требования: чистый код с комментариями, обработка ошибок, README с установкой.
Сначала напиши план реализации (3-5 шагов).
Затем код.
Затем инструкцию по запуску.

Self-correction loop:

  • Шаг 1: сгенерировать код
  • Шаг 2: AI Reviewer проверяет на баги, безопасность, соответствие ТЗ
  • Шаг 3: при замечаниях → рефакторинг
  • Шаг 4: финальная проверка без замечаний

Блок 5: Дизайн-задачи (для новичков)

Инструменты (бесплатные):

  • Canva — соцсети, презентации, простые логотипы
  • Figma — UI/UX, макеты сайтов
  • Leonardo.ai / Bing Image Creator — генерация изображений
  • Remove.bg — обработка фото

Автоматизация дизайна:

  • AI Agent анализирует ТЗ дизайна
  • Генерирует подробный промпт для генератора изображений
  • Создаёт ТЗ для Canva/Figma с размерами, цветами, шрифтами
  • Делает 3 варианта через AI-генератор
  • Self-correction: сверка с референсами, замечания по композиции/цвету/типографике

Инструкция для пользователя: отправляется в Telegram/Email вместе с результатами и ссылками на макеты.

Используются только бесплатные AI-агенты.
