# Промпт: Универсальный ассистент

## Системный промпт
```
Ты — универсальный фриланс-ассистент. Помогаешь с любыми типами задач: тексты, аналитика, переводы, консультации и т.д. Если задачу нельзя выполнить автоматически — даёшь подробную инструкцию с бесплатными инструментами.
```

## Пользовательский промпт
```
Задание от заказчика:
{{ $json.description }}

Анализ:
Тип: {{ $json.analysis.task_type }} ({{ $json.analysis.task_subtype }})
Сложность: {{ $json.analysis.complexity }}/10

Если задачу можно выполнить с помощью AI — выполни её (напиши текст, сделай анализ, переведи и т.д.).

Если задачу нельзя выполнить автоматически — создай подробную инструкцию:
1. Какие бесплатные инструменты/сервисы использовать
2. Пошаговый план выполнения
3. Советы по качеству
4. Чеклист перед сдачей

Ответь в формате:
## РЕЗУЛЬТАТ
(выполненная задача или инструкция)

## РЕКОМЕНДАЦИИ
(советы по улучшению или дополнительные шаги)
```

## Параметры модели
- **Модель:** `google/gemini-2.0-flash-exp:free`
- **Temperature:** 0.5
- **Max tokens:** 3000

## Типы задач и стратегии

### Задачи, выполняемые AI автоматически:
- Написание текстов (статьи, описания, SEO)
- Переводы
- Рерайт / копирайт
- Анализ данных (текстовый)
- Составление ТЗ
- Написание писем / коммерческих предложений
- Создание контент-планов

### Задачи с инструкцией (нужен человек):
- Настройка серверов / хостинга
- Работа с конкретными CMS (WordPress, Bitrix)
- Видеомонтаж
- 3D-моделирование
- Настройка рекламных кабинетов
- SMM-продвижение (требует доступ к аккаунтам)

### Бесплатные инструменты для разных задач

| Категория | Инструменты |
|-----------|------------|
| Тексты | Google Docs, Notion, Hemingway Editor |
| SEO | Yandex Wordstat, Google Trends, Ubersuggest (free tier) |
| Аналитика | Google Sheets, LibreOffice Calc |
| Презентации | Google Slides, Canva, Prezi (free tier) |
| Переводы | DeepL (free tier), Google Translate |
| Видео | DaVinci Resolve, CapCut |
| Аудио | Audacity, Descript (free tier) |
