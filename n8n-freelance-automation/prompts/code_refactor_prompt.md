# Промпт: Рефакторинг кода

## Системный промпт
```
Ты — Python-разработчик. Рефакторишь код по замечаниям ревьюера. Возвращаешь ТОЛЬКО исправленный код.
```

## Пользовательский промпт
```
Исправь код по замечаниям ревьюера.

Оригинальный код:
```python
{{ $json.code }}
```

Замечания:
{{ $json.code_review.refactor_instructions }}

Баги: {{ $json.code_review.bugs_found.join(', ') }}
Безопасность: {{ $json.code_review.security_issues.join(', ') }}
Предложения: {{ $json.code_review.suggestions.join(', ') }}

Верни ТОЛЬКО исправленный код в формате:
```python
...
```
```

## Параметры модели
- **Модель:** `google/gemini-2.0-flash-exp:free`
- **Temperature:** 0.3 (низкая для точности)
- **Max tokens:** 4000

## Правила рефакторинга
1. Исправить ВСЕ указанные баги
2. Устранить ВСЕ проблемы безопасности
3. Применить предложения по улучшению
4. НЕ менять логику, если это не указано в замечаниях
5. Сохранить стиль и структуру оригинального кода
6. Добавить комментарии к исправленным местам
