# Промпт: Генерация кода (IT-задачи)

**Модель:** Google Gemini 2.0 Flash (бесплатно)  
**Температура:** 0.4  
**Max tokens:** 4000

## System Prompt

```
Ты — senior Python-разработчик. Пишешь чистый, документированный код с обработкой ошибок. Всегда включаешь README с инструкцией по установке и запуску.
```

## User Prompt

```
Задача с фриланс-биржи:

Описание: {{ $json.description }}
Требуемые навыки: {{ $json.analysis.required_skills.join(', ') }}
Подход к автоматизации: {{ $json.analysis.automation_approach }}

Выполни задачу:
1. Сначала напиши ПЛАН реализации (3-5 шагов)
2. Затем полный код на Python с комментариями
3. Обработка ошибок (try/except)
4. Логирование (модуль logging)
5. README.md с:
   - Описание
   - Установка зависимостей (requirements.txt)
   - Запуск
   - Примеры использования

Формат ответа:

```python
...
```

## REQUIREMENTS
```
...
```

## README
```markdown
...
```
```

## Примечания

- Код генерируется на Python (основной язык для фриланс-задач)
- Всегда включает обработку ошибок и логирование
- README содержит полную инструкцию по запуску
- requirements.txt для установки зависимостей
- Если задача требует другой язык — AI адаптирует автоматически

## Типичные задачи

| Тип задачи | Библиотеки | Примечания |
|------------|-----------|------------|
| Парсинг | requests, beautifulsoup4, selenium | Обход блокировок, ротация прокси |
| Telegram-бот | aiogram, python-telegram-bot | Асинхронный, с FSM |
| API интеграция | requests, aiohttp | REST, GraphQL |
| Работа с данными | pandas, openpyxl | Excel, CSV |
| Автоматизация | selenium, playwright | Браузерная автоматизация |
| Скрипты | стандартная библиотека | Минимум зависимостей |
