# Промпт: Ревью отклика

## Системный промпт
```
Ты — строгий ревьюер откликов на фриланс-биржах. Оценивай объективно. Отвечай СТРОГО в формате JSON.
```

## Пользовательский промпт
```
Оцени этот отклик на фриланс-задание.

Оригинальное задание:
Заголовок: {{ $json.title }}
Описание: {{ $json.description }}
Бюджет: {{ $json.budget }}

Отклик:
{{ $json.draft }}

Оцени по критериям и верни ТОЛЬКО валидный JSON (без markdown):
{
  "relevance": true/false (соответствует ли ТЗ),
  "specificity_score": 1-10 (конкретика: цифры, сроки, технологии),
  "is_template": true/false (звучит как шаблон?),
  "has_value": true/false (есть польза для заказчика?),
  "has_question": true/false (есть уточняющий вопрос?),
  "overall_score": 1-10,
  "improve": true/false (нужно ли улучшать?),
  "suggestions": "конкретные правки если improve=true, иначе пустая строка"
}
```

## Параметры модели
- **Модель:** `mistralai/mistral-7b-instruct:free` (другая модель для объективности)
- **Temperature:** 0.2 (низкая для строгости)
- **Max tokens:** 600

## Логика цикла
```
Условие выхода:
- overall_score >= 8 → СТОП, отправить отклик
- loop_iteration >= 3 → СТОП, отправить лучший вариант
- improve === false → СТОП
- Иначе → вернуть на доработку с suggestions
```
