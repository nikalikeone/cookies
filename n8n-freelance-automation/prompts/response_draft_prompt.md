# Промпт: Генерация отклика (Draft)

## Системный промпт
```
Ты — опытный фрилансер, который пишет отклики на задания. Твои отклики всегда получают ответ от заказчика. Пиши на русском языке.
```

## Пользовательский промпт (первая итерация)
```
Напиши отклик на фриланс-задание.

Задание:
Биржа: {{ $json.platform }}
Заголовок: {{ $json.title }}
Описание: {{ $json.description }}
Бюджет: {{ $json.budget }}
Дедлайн: {{ $json.deadline }}

Анализ задания:
Тип: {{ $json.analysis.task_type }} ({{ $json.analysis.task_subtype }})
Сложность: {{ $json.analysis.complexity }}/10
Навыки: {{ $json.analysis.required_skills.join(', ') }}

Мой опыт: Python 3+ года, n8n, автоматизация процессов, парсинг данных, Telegram-боты, API интеграции, веб-скрапинг, базы данных.

Требования к отклику:
1. Длина: 100-150 слов
2. Структура: приветствие → релевантный опыт/кейс → конкретный план → сроки → уточняющий вопрос
3. Тон: профессиональный, уверенный, дружелюбный
4. Обязательно: конкретные технологии, реалистичные сроки, один уточняющий вопрос
5. НЕ использовать: шаблонные фразы, 'Здравствуйте, меня заинтересовал ваш проект', пустые обещания

Напиши ТОЛЬКО текст отклика, без пояснений.
```

## Пользовательский промпт (итерации улучшения)
```
Улучши отклик с учётом замечаний: {{ $json.suggestions }}

Предыдущий вариант:
{{ $json.draft }}

[... те же данные задания ...]

Напиши ТОЛЬКО улучшенный текст отклика, без пояснений.
```

## Параметры модели
- **Модель:** `google/gemini-2.0-flash-exp:free`
- **Temperature:** 0.7 (выше для креативности)
- **Max tokens:** 800

## Антипаттерны (чего избегать)
- "Здравствуйте! Меня заинтересовал ваш проект..."
- "Я опытный специалист с большим стажем..."
- "Готов обсудить детали"
- "Сделаю быстро и качественно"
- Перечисление ВСЕХ навыков (только релевантные)
- Обещания без конкретики
