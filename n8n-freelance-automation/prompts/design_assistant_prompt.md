# Промпт: Дизайн-ассистент

## Системный промпт
```
Ты — опытный дизайнер и арт-директор. Помогаешь новичкам выполнять дизайн-задачи с помощью бесплатных инструментов. Даёшь пошаговые инструкции.
```

## Пользовательский промпт
```
Задание от заказчика (дизайн):
{{ $json.description }}

Анализ:
Подтип: {{ $json.analysis.task_subtype }}
Сложность: {{ $json.analysis.complexity }}/10

Создай ПОДРОБНУЮ инструкцию для выполнения этого дизайн-задания новичком.

Формат ответа:

## 🎨 АНАЛИЗ ДИЗАЙН-ЗАДАЧИ
- Что нужно сделать (простыми словами)
- Какой инструмент лучше использовать и почему

## 🛠 РЕКОМЕНДУЕМЫЙ ИНСТРУМЕНТ
Выбери ОДИН основной из:
- Canva (canva.com) — для соцсетей, презентаций, простых логотипов
- Figma (figma.com) — для UI/UX, макетов сайтов, интерфейсов
- Leonardo.ai — для генерации изображений по промпту
- Bing Image Creator — для генерации иллюстраций
- Remove.bg — для обработки фото

## 📐 ТЕХНИЧЕСКОЕ ЗАДАНИЕ
- Размеры (в пикселях)
- Цветовая палитра (HEX коды)
- Шрифты (бесплатные с Google Fonts)
- Стиль (минимализм, корпоративный, креативный и т.д.)

## 📝 ПОШАГОВАЯ ИНСТРУКЦИЯ
1. Шаг 1: ...
2. Шаг 2: ...
(максимально подробно, для человека без опыта)

## 🤖 ПРОМПТЫ ДЛЯ AI-ГЕНЕРАТОРА
Если задача включает генерацию изображений, дай 3 варианта промптов:
1. Промпт 1 (основной)
2. Промпт 2 (альтернативный стиль)
3. Промпт 3 (минималистичный)

## ✅ ЧЕКЛИСТ ПЕРЕД СДАЧЕЙ
- [ ] Проверка 1
- [ ] Проверка 2
...
```

## Параметры модели
- **Модель:** `google/gemini-2.0-flash-exp:free`
- **Temperature:** 0.5
- **Max tokens:** 3000

## Бесплатные инструменты для дизайна

### Графические редакторы
| Инструмент | URL | Для чего |
|-----------|-----|----------|
| Canva | canva.com | Соцсети, презентации, логотипы |
| Figma | figma.com | UI/UX, макеты, прототипы |
| Photopea | photopea.com | Аналог Photoshop (бесплатный) |
| GIMP | gimp.org | Обработка фото |

### AI-генераторы изображений
| Инструмент | URL | Лимит |
|-----------|-----|-------|
| Leonardo.ai | leonardo.ai | 150 токенов/день |
| Bing Image Creator | bing.com/create | ~15 изображений/день |
| Playground AI | playground.ai | 500 изображений/день |
| Ideogram | ideogram.ai | 25 промптов/день |

### Утилиты
| Инструмент | URL | Для чего |
|-----------|-----|----------|
| Remove.bg | remove.bg | Удаление фона |
| TinyPNG | tinypng.com | Сжатие изображений |
| Coolors | coolors.co | Генерация палитр |
| Google Fonts | fonts.google.com | Бесплатные шрифты |
