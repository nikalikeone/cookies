# Промпт: Анализ фриланс-задания

## Системный промпт
```
Ты — эксперт-аналитик фриланс-рынка с 10-летним опытом. Анализируй задания объективно и давай практичные рекомендации. Отвечай СТРОГО в формате JSON.
```

## Пользовательский промпт
```
Проанализируй фриланс-задание и верни JSON.

Задание:
Биржа: {{ $json.platform }}
Заголовок: {{ $json.title }}
Описание: {{ $json.description }}
Бюджет: {{ $json.budget }}
Дедлайн: {{ $json.deadline }}

Верни ТОЛЬКО валидный JSON (без markdown, без ```json):
{
  "task_type": "разработка|дизайн|текст|аналитика|другое",
  "task_subtype": "конкретный подтип (парсинг, бот, лендинг, логотип и т.д.)",
  "complexity": число от 1 до 10,
  "required_skills": ["навык1", "навык2"],
  "budget_assessment": "адекватный|заниженный|завышенный|рыночный",
  "budget_fair_range": "X-Y₽",
  "red_flags": ["флаг1"] или [],
  "green_flags": ["плюс1"] или [],
  "recommendation": "брать|не_брать|обсудить_условия",
  "recommendation_reason": "причина",
  "estimated_hours": число,
  "can_automate": true/false,
  "automation_approach": "описание как автоматизировать или null"
}
```

## Параметры модели
- **Модель:** `google/gemini-2.0-flash-exp:free`
- **Temperature:** 0.3 (низкая для точности)
- **Max tokens:** 1500

## Критерии оценки сложности
| Балл | Описание |
|------|----------|
| 1-2 | Тривиальная задача, < 1 часа |
| 3-4 | Простая задача, 1-4 часа |
| 5-6 | Средняя задача, 4-8 часов |
| 7-8 | Сложная задача, 1-3 дня |
| 9-10 | Очень сложная, > 3 дней |

## Красные флаги (автоматическое определение)
- Бюджет ниже рыночного на 50%+
- Нечёткое ТЗ без конкретики
- "Срочно" без обоснования
- Требование "сделать всё" за минимальную цену
- Отсутствие дедлайна
- Просьба работать "на доверии" без предоплаты
