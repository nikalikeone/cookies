# 🤖 Freelance Automation Bot — n8n + AI

Полностью автоматизированная система для работы с фриланс-биржами через Telegram-бота.
Анализирует задания, генерирует отклики, пишет код и создаёт дизайн-инструкции — всё на **бесплатных AI-моделях**.

---

## 📋 Что делает бот

```
Вы отправляете задание → AI анализирует → генерирует отклик → выполняет задачу
```

### Поддерживаемые биржи
Kwork • FL.ru • LinkedIn • Profi.ru • YouDo • Habr Freelance • Freelansim • Weblancer • Upwork • Fiverr • Telegram-каналы

### 5 блоков автоматизации

| # | Блок | Описание |
|---|------|----------|
| 1 | **Входные данные** | Telegram Bot принимает задания в свободном или структурированном формате |
| 2 | **Анализ задания** | AI определяет тип, сложность, бюджет, красные флаги, рекомендацию |
| 3 | **Генерация отклика** | Self-correction loop: Draft → Review → Refine (до 3 итераций) |
| 4 | **IT-задачи** | Генерация кода + Code Review + Рефакторинг (self-correction loop) |
| 5 | **Дизайн-задачи** | Подробная инструкция для новичка с бесплатными инструментами |

## 🚀 Быстрый старт

### 1. Получите бесплатные ключи (5 минут)

| Сервис | Ссылка | Что получите |
|--------|--------|-------------|
| **OpenRouter** | [openrouter.ai](https://openrouter.ai) | API ключ для бесплатных AI моделей |
| **Telegram BotFather** | [@BotFather](https://t.me/BotFather) | Токен Telegram бота |

### 2. Установите n8n

```bash
# Docker (рекомендуется)
docker run -it --rm --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n

# Или npm
npm install n8n -g && n8n start
```

### 3. Импортируйте workflow

1. Откройте `http://localhost:5678`
2. Импортируйте файл `freelance_automation_workflow.json`
3. Настройте credentials (см. [SETUP_GUIDE.md](SETUP_GUIDE.md))
4. Активируйте workflow

### 4. Отправьте первое задание боту

```
Новый заказ
Биржа: Kwork
Заголовок: Нужен парсер Wildberries
Описание: Написать скрипт для парсинга карточек товаров
Бюджет: 5000₽
Дедлайн: 3 дня
```

## 🔄 Self-Correction Loops

### Цикл генерации отклика

```
Итерация 1: Gemini генерирует черновик отклика
     ↓
Итерация 1: Mistral оценивает (score 1-10)
     ↓
Score < 8? → Gemini улучшает с учётом замечаний
     ↓
Итерация 2: Mistral оценивает повторно
     ↓
Score >= 8 ИЛИ 3 итерации → Отправка финального отклика
```

### Цикл генерации кода

```
Шаг 1: Gemini генерирует код по ТЗ
     ↓
Шаг 2: Mistral проверяет (баги, безопасность, соответствие ТЗ)
     ↓
Не одобрен? → Gemini рефакторит по замечаниям
     ↓
Шаг 3: Mistral проверяет повторно
     ↓
Одобрен ИЛИ 3 итерации → Отправка кода с ревью
```

## ⚙️ Кастомизация

### Изменение профиля фрилансера

В ноде **"Генерация отклика (Draft)"** измените секцию "Мой опыт":

```
Мой опыт: [ваши навыки и опыт]
```

### Добавление новых бирж

В ноде **"Парсинг сообщения"** добавьте домен в объект `platforms`:

```javascript
const platforms = {
  'kwork.ru': 'Kwork',
  'новая-биржа.ru': 'Новая Биржа',
  // ...
};
```

### Смена AI-модели

В любом HTTP Request ноде измените поле `model`:

```json
{
  "model": "meta-llama/llama-3.1-8b-instruct:free"
}
```

### Настройка количества итераций

В ноде **"Инициализация цикла отклика"** измените `max_iterations`:

```javascript
max_iterations: 5  // по умолчанию 3
```

## 🛡 Безопасность

- API ключи хранятся в n8n Credentials (зашифрованы)
- Бот работает только с вашим Chat ID
- Никакие данные не отправляются третьим сторонам (кроме AI API)
- Код не выполняется автоматически — только генерируется

## 🐛 Устранение неполадок

| Проблема | Решение |
|----------|---------|
| Бот не отвечает | Проверьте: workflow активирован? Токен верный? n8n доступен из интернета? |
| Ошибка 429 (rate limit) | Подождите 1 час или смените модель на резервную |
| AI возвращает не JSON | В Code нодах есть fallback. Понизьте temperature |
| Webhook не работает | Используйте `n8n start --tunnel` или ngrok |
| Длинные сообщения обрезаются | Telegram лимит 4096 символов. Код отправляется отдельным сообщением |
