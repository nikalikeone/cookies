## 🚀 Возможности

### Блок 1: Ввод данных через Telegram
- 📱 Отправляете задание боту в Telegram (структурированный формат или свободный текст)
- 🔗 Автоматическое определение платформы по URL (Kwork, FL.ru, LinkedIn и др.)
- 💰 Парсинг бюджета с определением валюты (₽, $, €)
- 📨 Поддержка пересланных сообщений из Telegram-каналов

### Блок 2: AI-анализ задания
- 🧠 Определение типа задачи (разработка, дизайн, текст, маркетинг)
- 📊 Оценка сложности (1-10)
- 🎯 Определение требуемых навыков
- 💵 Оценка адекватности бюджета
- 🚩 Выявление красных флагов (нечёткое ТЗ, заниженный бюджет, подозрительная срочность)
- ✅ Рекомендация: брать / не брать / уточнить

### Блок 3: Генерация отклика (Self-Correction Loop)
- ✍️ Генерация профессионального отклика
- 🔄 Цикл самопроверки: Draft → Review → Refine
- 📏 Контроль качества: оценка конкретики, уникальности, пользы для заказчика
- 🎯 Условие выхода: 3 итерации ИЛИ оценка ≥ 8/10

### Блок 4: Выполнение IT-задач
- 💻 Генерация кода (Python) с планом реализации
- 📝 Автоматическое создание README и requirements.txt
- 🔍 Code Review: проверка на баги, безопасность, соответствие ТЗ
- 🔄 Цикл рефакторинга (макс 3 итерации)

### Блок 5: Дизайн-задачи (инструкции для новичков)
- 🎨 Подробная пошаговая инструкция
- 🛠 Список бесплатных инструментов (Canva, Figma, Leonardo.ai, Photopea)
- 🖼 Готовые промпты для AI-генерации изображений
- ✅ Чеклист перед сдачей работы

1. **n8n** — установлен и запущен (self-hosted или n8n.cloud)

```bash

# 2. Откройте n8n в браузере
# http://localhost:5678

# 3. Импортируйте workflow
# Меню → Import from File → выберите freelance_automation_workflow.json

# 4. Настройте credentials (см. разделы ниже)

# 5. Активируйте workflow
```

## 🔧 Настройка n8n

```bash

services:
  n8n:
    image: n8nio/n8n

      - n8n_data:/home/node/.n8n
```

## 🤖 Настройка Telegram бота

### Шаг 1: Создание бота

1. Откройте Telegram, найдите [@BotFather](https://t.me/BotFather)
2. Отправьте `/newbot`
3. Введите имя бота (например: `Freelance Helper Bot`)
4. Введите username (например: `my_freelance_helper_bot`)
5. **Скопируйте токен** (формат: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)

### Шаг 2: Настройка в n8n

1. Откройте n8n → **Settings** → **Credentials**
2. Нажмите **Add Credential** → выберите **Telegram API**
3. Вставьте токен бота
4. Нажмите **Save**
5. В workflow дважды кликните на ноду **Telegram Trigger**
6. Выберите созданный credential

### Шаг 3: Настройка Webhook

Для self-hosted n8n нужен публичный URL:

```bash
# Вариант A: ngrok (для тестирования)
ngrok http 5678
# Скопируйте URL (https://xxxx.ngrok.io)
# Установите в n8n: Settings → WEBHOOK_URL

# Вариант B: Cloudflare Tunnel (бесплатно, для продакшена)
cloudflared tunnel --url http://localhost:5678
```

## 🧠 Настройка OpenRouter (бесплатные AI)

### Шаг 1: Регистрация

1. Перейдите на [openrouter.ai](https://openrouter.ai)
2. Зарегистрируйтесь (можно через Google/GitHub)
3. Перейдите в **Keys** → **Create Key**
4. Скопируйте API-ключ (формат: `sk-or-v1-...`)

### Шаг 2: Настройка в n8n

1. Откройте n8n → **Settings** → **Credentials**
2. Нажмите **Add Credential** → выберите **Header Auth**
3. Заполните:
   - **Name**: `OpenRouter API Key`
   - **Header Name**: `Authorization`
   - **Header Value**: `Bearer sk-or-v1-ваш_ключ_здесь`
4. Нажмите **Save**
5. Обновите все HTTP Request ноды — выберите этот credential

### Используемые бесплатные модели

| Модель | Провайдер | Назначение в workflow | Лимиты |
|--------|-----------|----------------------|--------|
| `google/gemini-2.0-flash-exp:free` | Google | Анализ задания, генерация кода | ~50 req/day |
| `mistralai/mistral-small-3.1-24b-instruct:free` | Mistral | Генерация откликов | ~50 req/day |
| `meta-llama/llama-4-maverick:free` | Meta | Ревью откликов и кода | ~50 req/day |

> ⚠️ Бесплатные лимиты могут меняться. Актуальные лимиты: [openrouter.ai/docs#limits](https://openrouter.ai/docs#limits)

## ⚙️ Как это работает

### Поток обработки

1. **Вы отправляете задание** боту в Telegram
2. **Парсер** извлекает данные: платформа, описание, бюджет, дедлайн
3. **AI-анализ** (Gemini) оценивает задание: тип, сложность, красные флаги, рекомендация
4. **Маршрутизатор** направляет по типу задачи:
   - 💻 **Code Task** → генерация кода + code review + рефакторинг
   - 🎨 **Design Task** → пошаговая инструкция с бесплатными инструментами
   - 💬 **Response Only** → только генерация отклика
5. **Генерация отклика** (Mistral) — для всех типов задач
6. **Self-Correction Loop** — ревью (Llama) → доработка → повтор (макс 3 раза)
7. **Результат** отправляется в Telegram:
   - 📊 Анализ задания
   - 💬 Готовый отклик
   - 💻 Код (если IT-задача)
   - 🎨 Инструкция (если дизайн-задача)

### Self-Correction Loop (отклик)

```
Draft (Mistral) → Review (Llama) → Score < 8? → Refine (Mistral) → Review → ...
                                   Score ≥ 8? → ✅ Финальный отклик
                                   3 итерации? → ✅ Берём лучший вариант
```

### Self-Correction Loop (код)

```
Generate (Gemini) → Review (Llama) → Bugs? → Refactor (Gemini) → Review → ...
                                     Clean? → ✅ Финальный код
                                     3 итерации? → ✅ Берём текущий вариант
```

## 🔧 Устранение неполадок

### Бот не отвечает

1. Проверьте, что workflow **активирован** (зелёный тумблер)
2. Проверьте Webhook URL: `Settings → WEBHOOK_URL`
3. Проверьте логи: `Executions → All Executions`
4. Убедитесь, что Telegram credential настроен правильно

### Ошибка AI (пустой ответ)

1. Проверьте API-ключ OpenRouter
2. Проверьте лимиты: [openrouter.ai/activity](https://openrouter.ai/activity)
3. Попробуйте альтернативную модель (см. раздел "Альтернативные AI-провайдеры")
4. Увеличьте `timeout` в HTTP Request нодах

### Ошибка парсинга JSON

AI иногда возвращает невалидный JSON. Парсер в workflow обрабатывает:
- JSON обёрнутый в ` ```json ... ``` `
- JSON с лишним текстом до/после
- Если парсинг не удался — используется fallback

### Telegram: сообщение слишком длинное

Workflow автоматически разбивает сообщения на части по 4000 символов. Если всё равно ошибка — уменьшите `max_tokens` в HTTP Request нодах.

## ❓ FAQ

**Q: Сколько стоит использование?**  
A: Бесплатно. n8n self-hosted бесплатен, все AI-модели используют бесплатные тарифы.

**Q: Какие лимиты у бесплатных AI?**  
A: ~50-1500 запросов в день в зависимости от провайдера. Для 5-10 заданий в день — более чем достаточно.

**Q: Можно ли добавить свои промпты?**  
A: Да, отредактируйте `jsonBody` в HTTP Request нодах. Промпты находятся в поле `messages[].content`.

**Q: Как добавить новую биржу?**  
A: Добавьте домен в функцию `detectPlatform()` в ноде "Parse Input Message".

**Q: Можно ли использовать платные модели?**  
A: Да, замените `model` в HTTP Request нодах. Например: `openai/gpt-4o`, `anthropic/claude-3.5-sonnet`.

**Q: Бот может сам отправлять отклики на биржи?**  
A: Нет, бот генерирует текст отклика — вы копируете и отправляете сами. Автоматическая отправка нарушает правила бирж.

**Q: Как обновить workflow?**  
A: Импортируйте новую версию `freelance_automation_workflow.json`. Credentials сохранятся.
