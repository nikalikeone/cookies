# N8N Автоматизация для Фриланс-бирж

Полностью автоматизированная система для работы с фриланс-биржами (Kwork, FL.ru, LinkedIn, Profi.ru, YouDo, Telegram каналы).

## Возможности

### 1. Автоматический анализ заданий
- Определение типа задачи (разработка, дизайн, текст, другое)
- Оценка сложности (1-10)
- Выявление требуемых навыков
- Оценка реалистичности бюджета
- Обнаружение "красных флагов"
- Рекомендация: брать или не брать задание

### 2. Генерация откликов с самопроверкой
- Self-correction loop: до 3 итераций улучшения
- Проверка на соответствие ТЗ
- Оценка конкретности и профессионализма
- Автоматическое улучшение на основе ревью

### 3. Выполнение IT-задач
- Генерация плана реализации
- Написание кода с комментариями
- Автоматическое код-ревью
- Проверка на баги и безопасность
- Создание README с инструкциями

### 4. Помощь с дизайн-задачами
- Подробные инструкции для новичков
- Промпты для AI генераторов (Leonardo.ai, Bing Image Creator)
- Техзадания для Canva/Figma
- Чеклисты проверки качества

## Используемые бесплатные AI модели

1. **Google Gemini 2.0 Flash** (через OpenRouter)
   - Анализ заданий
   - Код-ревью
   - Генерация дизайн-инструкций

2. **Mistral 7B Instruct** (через OpenRouter)
   - Генерация откликов

3. **Llama 3.1 8B** (через OpenRouter)
   - Генерация кода

Все модели доступны бесплатно через [OpenRouter.ai](https://openrouter.ai/)

## Установка и настройка

### Шаг 1: Установите n8n

```bash
npm install -g n8n
```

Или используйте Docker:

```bash
docker run -it --rm \
  --name n8n \
  -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  n8nio/n8n
```

### Шаг 2: Получите API ключи

#### OpenRouter API Key (БЕСПЛАТНО)
1. Зарегистрируйтесь на [OpenRouter.ai](https://openrouter.ai/)
2. Перейдите в раздел "Keys"
3. Создайте новый API ключ
4. **ВАЖНО**: Free tier предоставляет ограниченное количество запросов. Для production используйте платный план или alternative API.

#### Telegram Bot Token (БЕСПЛАТНО)
1. Найдите в Telegram бота [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям
4. Сохраните токен вида: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`

### Шаг 3: Импортируйте workflow

1. Откройте n8n (обычно `http://localhost:5678`)
2. Нажмите "Add workflow" → "Import from file"
3. Выберите файл `freelance-automation-master.json`
4. Workflow будет импортирован

### Шаг 4: Настройте credentials

#### OpenRouter API
1. В n8n перейдите в "Credentials" → "Add Credential"
2. Выберите "HTTP Header Auth"
3. Создайте credential с именем "OpenRouter API Key":
   - Header Name: `Authorization`
   - Header Value: `Bearer ВАШ_API_КЛЮЧ_OPENROUTER`

#### Telegram Bot API
1. В n8n перейдите в "Credentials" → "Add Credential"
2. Выберите "Telegram API"
3. Введите токен от BotFather

### Шаг 5: Активируйте workflow

1. Откройте импортированный workflow
2. Нажмите "Active" в правом верхнем углу
3. Workflow начнёт слушать сообщения от Telegram бота

## Использование

### Формат сообщения боту

Отправьте боту сообщение в следующем формате:

```
Новый заказ
Биржа: Kwork
Ссылка: https://kwork.ru/projects/12345
Заголовок: Нужен парсер Wildberries
Описание: Требуется написать Python скрипт для парсинга товаров с Wildberries. Необходимо собирать название, цену, рейтинг, количество отзывов. Данные сохранять в Excel.
Бюджет: 5000₽
Дедлайн: 3 дня
```

### Минимальный формат

Можно отправить просто описание задачи, остальные поля необязательны:

```
Описание: Нужен Telegram бот для учёта расходов с кнопками добавления категорий
```

### Что происходит после отправки

1. **Подтверждение** - Бот пришлёт сообщение "Задание принято в обработку"
2. **Анализ** (10-30 сек) - AI анализирует задание и отправляет результат:
   - Тип задачи
   - Сложность
   - Требуемые навыки
   - Оценка бюджета
   - Красные флаги (если есть)
   - Рекомендация: брать или не брать

3. **Генерация отклика** (20-60 сек) - Если рекомендация "брать":
   - Генерируется черновик отклика
   - AI проверяет качество
   - При необходимости улучшает (до 3 итераций)
   - Отправляет финальный вариант с оценкой

4. **Выполнение задачи** (30-120 сек) - В зависимости от типа:

   **Для IT-задач:**
   - Генерируется план реализации
   - Пишется код с комментариями
   - Проводится код-ревью
   - Создаётся README
   - Отправляется готовое решение

   **Для дизайн-задач:**
   - Создаётся подробная инструкция
   - Генерируются промпты для AI-генераторов
   - Даётся техзадание для Canva/Figma
   - Предоставляется чеклист проверки

## Структура workflow

```
Telegram Trigger
    ↓
Parse Message (парсинг входящего сообщения)
    ↓
Check Error (проверка валидности)
    ├→ Send Error (если ошибка)
    └→ Send Acknowledgement (подтверждение)
        ↓
    AI Analyze Task (анализ с Google Gemini)
        ↓
    Parse Analysis (обработка результата)
        ↓
    Send Analysis (отправка анализа)
        ↓
    Check Recommendation (если рекомендация "брать")
        ↓
    Generate Draft (Mistral 7B)
        ↓
    Review Draft (Google Gemini) ←┐
        ↓                          │
    Check Improvement Needed       │
        ├→ [loop до 3 раз] ────────┘
        └→ Send Final Response
            ↓
        ├→ IT Task Path (Llama 3.1)
        │   ├→ Generate Code
        │   ├→ Review Code
        │   └→ Send Code
        │
        └→ Design Task Path (Google Gemini)
            ├→ Generate Design Guide
            └→ Send Design Guide
```

## Лимиты и ограничения

### Бесплатные API (OpenRouter)
- **Google Gemini 2.0 Flash:** ~10-20 запросов/мин
- **Mistral 7B:** ~5-10 запросов/мин
- **Llama 3.1 8B:** ~5-10 запросов/мин

При превышении лимитов workflow может замедлиться или временно не работать. Для продакшена рекомендуется:
1. Использовать платный план OpenRouter ($5-20/мес)
2. Добавить rate limiting в workflow
3. Настроить fallback на альтернативные модели

### Telegram Bot
- Максимальная длина сообщения: 4096 символов
- Для длинных ответов (код, инструкции) сообщения разбиваются на части

## Расширенная конфигурация

### Изменение AI моделей

В каждом HTTP Request узле можно изменить модель в параметре `model`:

**Альтернативы для анализа:**
- `google/gemini-2.0-flash-exp:free` (по умолчанию)
- `anthropic/claude-instant-v1:free` (если доступно)
- `meta-llama/llama-3.1-70b-instruct:free` (медленнее, но качественнее)

**Альтернативы для генерации откликов:**
- `mistralai/mistral-7b-instruct:free` (по умолчанию)
- `google/gemini-2.0-flash-exp:free`
- `meta-llama/llama-3.1-8b-instruct:free`

### Настройка промптов

Промпты находятся в узлах HTTP Request в параметре `messages`. Вы можете:
- Изменить описание своего опыта
- Добавить конкретные кейсы
- Изменить стиль откликов (более формальный/неформальный)
- Добавить специфические требования для вашей ниши

### Добавление уведомлений

Можете добавить узлы для отправки уведомлений в:
- Email (SMTP узел)
- Slack
- Discord
- Webhooks

## Troubleshooting

### Бот не отвечает
1. Проверьте, что workflow активирован (зелёная галочка)
2. Проверьте credentials для Telegram
3. Откройте "Executions" и посмотрите логи ошибок

### Ошибки AI запросов
1. Проверьте OpenRouter API key
2. Проверьте баланс на OpenRouter (для free tier)
3. Попробуйте другую модель (могут быть временные проблемы)

### Некорректные ответы
1. Улучшите промпты (добавьте больше контекста)
2. Увеличьте `maxIterations` в self-correction loop
3. Используйте более мощные модели (платные)

## Best Practices

1. **Проверяйте отклики перед отправкой** - AI может ошибаться, всегда читайте финальный вариант
2. **Дополняйте анализ своим опытом** - AI не знает специфику конкретных заказчиков
3. **Не автоматизируйте отправку** - используйте workflow как помощника, а не замену
4. **Обновляйте промпты** - добавляйте успешные кейсы в промпты
5. **Следите за лимитами** - бесплатные API имеют ограничения
