# n8n: Автоматизация фриланс-заказов (free AI)

Этот файл описывает готовую структуру автоматизации n8n для анализа заказов, генерации откликов и выполнения IT/дизайн-задач с использованием бесплатных AI-моделей. Импортируемый пример workflow находится в `n8n-freelance-workflow.json`.

## 1) Общая логика

1. Telegram Trigger → парсинг входного сообщения.
2. Анализ задания AI (бесплатные модели).
3. Генерация отклика с самопроверкой (до 3 итераций).
4. Ветка IT-задач: генерация кода + ревью + правки.
5. Ветка дизайн-задач: промпты, техзадание, самопроверка.
6. Если задача не выполнима бесплатными API — отправляется инструкция пользователю.

## 2) Формат входного сообщения (Telegram)

```
Новый заказ
Биржа: Kwork
Ссылка: https://kwork.ru/...
Заголовок: Нужен парсер Wildberries
Описание: [копирую текст полностью]
Бюджет: 5000₽
Дедлайн: 3 дня
```

## 3) Бесплатные модели и провайдеры

Используйте любой один или несколько провайдеров:

- OpenRouter (free tier):
  - `mistralai/mistral-7b-instruct:free`
  - `meta-llama/llama-3.1-8b-instruct:free`
- Groq (free tier):
  - `llama-3.1-8b-instant`
- Gemini (free tier):
  - `gemini-1.5-flash`

В workflow предусмотрено поле `ai_provider` и `ai_model`, чтобы быстро переключать модели.

## 4) Промпты (ключевые)

### Анализ задания

```
Проанализируй фриланс-задание. Определи:
1. Тип задачи (разработка, дизайн, текст, другое)
2. Сложность (1-10)
3. Требуемые навыки
4. Реалистичность бюджета
5. Красные флаги (нечёткое ТЗ, слишком дешево, срочно без причины)
6. Рекомендация: брать/не брать + причина
Ответ верни в JSON с ключами:
type, difficulty, skills, budget_ok, red_flags, recommendation, reason
```

### Отклик — Draft

```
Напиши отклик на фриланс-задание.
Задание: {{$json.description}}.
Мой опыт: Python 3 года, n8n, автоматизация, парсинг, боты Telegram.
Тон: профессиональный, уверенный, но не высокомерный.
Длина: 100-150 слов.
Структура: приветствие → релевантный кейс → сроки → вопрос по уточнению.
```

### Отклик — Review

```
Оцени этот отклик на фриланс-задание по критериям:
- Соответствует ли ТЗ заказчика? (да/нет)
- Есть ли конкретика (цифры, сроки, технологии)? (оценка 1-10)
- Звучит ли как шаблон? (да/нет)
- Есть ли явная польза для заказчика? (да/нет)
- Что улучшить? (конкретные правки)
Если оценка < 8/10 или есть критические замечания → верни JSON:
{"improve": true, "score": 0, "suggestions": "..."}
Иначе верни JSON:
{"improve": false, "score": 9, "suggestions": ""}
```

### Отклик — Refine

```
Улучши отклик с учётом замечаний: {{$json.suggestions}}
Сохрани структуру и тон. Длина: 100-150 слов.
```

### IT-задачи (код)

```
Ты Python-разработчик. Задача: {{$json.task_description}}.
Требования: чистый код с комментариями, обработка ошибок, README с установкой.
Сначала напиши план реализации (3-5 шагов).
Затем код.
Затем инструкцию по запуску.
```

### Дизайн-задачи (инструкция)

```
Сделай инструкцию для дизайна:
- Инструменты: Canva, Figma, Leonardo.ai/Bing Image Creator, Remove.bg
- Промпты для генератора изображений
- Техзадание с размерами, цветами, шрифтами
- 3 варианта дизайна
- Самопроверка по композиции/цвету/типографике
```

## 5) Правило fallback (когда free tier не подходит)

Если токены/лимиты бесплатного API исчерпаны:
- AI возвращает специальный JSON `{needs_manual: true, steps: "..."}`
- n8n отправляет пользователю инструкцию по самостоятельному запуску в нужном сервисе.

## 6) Выходные каналы

- Telegram Reply: финальный отклик или инструкции по задаче.
- Email (опционально): отчёт, оценка, вложения.
